# 本活動（暫名：歌神杯／古吉音樂季）

淡江大學共鳴箱古典吉他社 2027 春季音樂活動的企劃與網站。

- `site/`：比賽網站靜態原型（GitHub Pages）。內容只改 `site/content.js`。`site/staff.html` 是工作人員導覽頁。
- `output/`：企劃文件的 Markdown／Excel 原稿（正式版在 Google Drive「歌神杯」資料夾）。
- `tools/`：產生預算、活動總表、補助時程試算表的腳本（`budget_model.py` 是所有金額的唯一來源）。
- 決策紀錄以 Drive 上的《歌神杯_專案背景與決策紀錄_v3.md》為準。
