# 專案中控台設計系統 v4：雜誌編輯大膽風

參考：Bloomberg Businessweek（Richard Turley 時期）的編輯式大膽風。把中控台做成一本每週出刊的音樂雜誌。

## 概念
- **報頭**：黑底，放刊名「本活動」、期數（資料快照日期）、倒數「N 天後開演」。
- **目錄式分頁**：桌機頂部 8 格分頁，用粗黑線分隔，數字 1–8 是快捷鍵。目前頁面的格子填上該頁的訊號色。
- **跨頁開頭**：每頁頂部是滿版訊號色，左邊放超大標題，右邊放一個超大數字（工作 56、關卡 0/13、經費 116K 等）。
- **封面（總覽）**：螢光黃滿版。倒數數字用 Anton 字體排得很大，並用桃紅與藍色錯版陰影營造印刷感。下方放三行封面標題、四格數據，以及「號外」桃紅警示框。

## 色彩（每個跨頁最多黑、白＋一個訊號色）
| Token | 值 | 用途 |
|---|---|---|
| `--yellow` | #ffe500 | 封面、工作、人員；hover、聚焦中的輸入框 |
| `--pink` | #ff2e88 | 關卡、經費；逾期、卡住、缺口、號外 |
| `--blue` | #1a2bff | 時間軸、待決、上手；進行中、今天線、目標線 |
| `--ink` / `--paper` | #0b0b0b / #ffffff | 深色模式反轉為 #f4f2ea / #0b0b0b |

訊號色上的文字一律用黑色（黃、桃紅），藍底則用白色，對比度皆達 AA 以上。

## 字體
- 標題：Noto Sans TC 900，字距 -0.02 到 -0.05em。
- 數字：Anton（窄體 grotesque），用於倒數、日期、編號、金額。
- 內文與說明：Noto Serif TC 400/700。圖說用斜體小字。

## 形狀與質感
- 圓角 0、不用柔和陰影。按鈕使用 3px 實心偏移陰影，按下時陷入。
- 版面分隔用 3px 粗線，表格列之間用 1px 細線。
- 色塊上用半色調網點（radial-gradient 7px）並加上漸層遮罩。

## 動態（硬切，不用柔和緩動）
- 換頁時，跨頁色塊以 clip-path 從左向右擦入（260ms），標題與大數字「砸進」定位（overshoot cubic-bezier）。
- 封面倒數數字從錯版位置收合到對位（700ms）。
- 甘特圖長條與經費長條從左側長出。跳到某項工作時，以 steps(3) 桃紅閃爍。
- `prefers-reduced-motion` 下關閉所有動畫。

## 保留的功能
8 個 view、篩選、搜尋、排序、展開、前置工作跳轉、快捷鍵 1–8 與 /、淺色／系統／深色主題、手機底部分頁加「更多」選單、複製連結、localStorage 記住篩選與主題。
