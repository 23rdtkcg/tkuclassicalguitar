# 專案中控台設計系統（tools/dashboard_template.html）

模式：Operate（幹部完成任務用的工具）。視覺語言：舞台監督的提詞本——安靜、精準，只在總覽簡報區保留一盞舞台燈。

## 色彩（語意 token，淺色／深色兩套，依系統或使用者切換）
| Token | 用途 |
|---|---|
| `--page` `--panel` `--panel-2` `--sunken` | 頁面底、內容面板、側欄層、內嵌區 |
| `--ink` `--ink-2` `--ink-3` | 主要文字、次要文字、說明文字（皆 ≥4.5:1） |
| `--amber` / `--amber-ink` / `--amber-wash` | 主色：填色、文字用深琥珀、淡底（目前位置、下一關、今天） |
| `--danger` `--warn` `--ok` `--info` ＋ `-wash` | 逾期與卡住、總表缺漏與未指派、完成、進行中 |
| `--g-*` | 五個組別標記，只用在小色塊與甘特色塊 |

## 字體
- 全站 Noto Sans TC（400／500／700）；數字、日期、編號用 IBM Plex Mono（等寬數字）。
- 唯一的展示字：總覽倒數數字用 Noto Serif TC 900。
- 字級（固定）：12／13／15（手機 16）／16／19／23／28／56（手機 44）。

## 間距、圓角、陰影
- 4px 基準：4／8／12／16／24／32／48。
- 圓角：6（小元件）／10（按鈕、輸入）／14（面板）。
- 陰影三層，皆有位移與模糊：`--shadow-1` 面板、`--shadow-2` 簡報區、`--shadow-3` 底部選單與提示。

## 動態
- 時間：120ms（hover）／200ms（狀態）／320ms（展開、切頁）；緩動 `cubic-bezier(.16,1,.3,1)`。
- 唯一的編排時刻：第一次進總覽時，簡報區舞台燈亮起（900ms）。
- `prefers-reduced-motion`：全部動畫與轉場縮到 1ms，不再播放舞台燈。

## 版型與響應式
- ≥1024px：左側固定導覽（248px）＋主欄，最寬 1240px。
- <1024px：頂部精簡列＋底部 5 格分頁（總覽、時間軸、工作、關卡、更多）；「更多」用 `<dialog>` 底部選單。
- <768px：時間軸預設「依月份」清單；工作篩選收進「篩選」按鈕；表格改成卡片列。
- 工作列用容器查詢（`container: tl`）依所在面板寬度切換 7 欄／6 欄／堆疊。
- 觸控裝置：按鈕、分段、晶片按鈕最小 44px；輸入框 16px。

## 元件
按鈕（預設、primary、ghost、icon）、分段控制、搜尋與下拉、狀態標籤（文字＋圖示，不只靠顏色）、可展開工作列、關卡時間線、待決清單、名冊、帳本數字列、方案長條圖、提示 toast、底部選單。
