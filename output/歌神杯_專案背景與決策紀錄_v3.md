## 4. 比賽規則（已確認）

| 項目 | 規則 |
|---|---|
| 組別 | 只有一組「歌唱組」 |
| 資格 | 全國大專校院在學生（伴奏者是否限學生：待章程決定，參考阿勃勒盃不限） |
| 海選 | 線上影音海選，影片 1～2 分鐘，3 位評審線上評分 |
| 決賽 | 週五晚上一輪，10～12 組 |
| 台上人數 | 主唱 1＋伴奏最多 2，總共 ≤ 3 人 |
| 伴奏 | 自彈自唱或樂手伴奏，或伴奏音檔（事先繳交、不可含主唱人聲） |
| 樂器 | 只收可直接接線的樂器（木吉他、電子琴等）；木箱鼓可；不收鼓組；主辦不提供音箱 |
| 主辦提供 | 麥克風、樂器接線、音檔播放 |
| 曲目 | 一首，5 分鐘內 |
| 評審 | 3 位（海選與決賽同一組） |
| 評分 | 參考金韶：詮釋 40%、音色 20%、台風 20%、整體和諧度 20% |
| 同分 | 評審討論後投票 |
| 出場順序 | 公開抽籤或電腦隨機，錄影存證 |
| 獎項 | 前三名（以贊助品為主、現金壓低）＋觀眾掃碼投票人氣獎 |
| 計分 | 紙本評分表＋Google 試算表，兩人各算一次，一致才公布 |
| 直播 | 第一年不直播，只錄影存檔 |

🆕 查證：
- **著作權**：著作權法第 55 條，同時符合「非以營利為目的」「未對觀眾直接或間接收費」「未對表演人支付報酬」，可主張合理使用（智慧局月刊、淡江時報 Q&A）。待確認：獎金算不算「報酬」、市集販售算不算「間接收費」。錄影上網不在第 55 條範圍 → **完整翻唱影片不公開上網**，只用 30 秒內片段。
- **獎金扣稅**：屬「競技、競賽及機會中獎之獎金」；國內居住者扣繳 10%，每次應扣稅額 ≤ NT$2,000（獎金約 ≤ NT$20,000）免先扣但仍要列單申報；非居住者一律 20%。由學校出納或社團申報：待確認。
- 建議獎金：冠 5,000／亞 3,000／季 2,000／人氣 1,000（共 NT$11,000，全部由贊助支付；沒有贊助就只發獎狀＋獎品）。
- 章程草案、報名表欄位、個資與肖像授權、評分表、核分表、通知信範本：見《本活動_比賽章程草案》。
