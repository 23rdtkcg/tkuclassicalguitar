# 本活動｜比賽網站規格（一頁版）

> 依據：MD 第 5 節。原型程式碼在 GitHub repo `23rdtkcg/tkuclassicalguitar` 的 `site/` 資料夾（分支 `claude/tender-pascal-4oczpg`）。

## 結論
做一個**只有一頁的靜態網站**，放在 GitHub Pages（免費）。報名用**嵌入的 Google 表單**。網站壞掉也不會影響報名資料。

**術語**
- **靜態網站**：只有 HTML、CSS 檔案，沒有後端程式、沒有資料庫。改內容就是改檔案。
- **GitHub Pages**：GitHub 提供的免費網站空間。檔案放上去就有網址。
- **嵌入**：把 Google 表單「貼」進網頁裡，看起來像網站的一部分，但資料其實存在 Google。

## 做什麼／不做什麼

| 做 | 不做（原因：第一次辦，維護風險與個資風險太高） |
|---|---|
| 活動介紹、比賽章程摘要、時程、FAQ | 會員系統、登入 |
| 嵌入 Google 報名表 | 自己寫的影片上傳 |
| 晉級名單公告、得獎公告 | 自己的資料庫 |
| 手機看得清楚 | 線上評分系統（評分用 Google 試算表） |

## 頁面區塊（由上到下）
1. **頂部**：活動名稱（暫名）、日期、「我要報名」按鈕。
2. **活動介紹**：兩天各做什麼。
3. **重要時程**：報名、海選、公告、決賽日期。
4. **比賽章程摘要**＋完整章程連結（Google 文件或 PDF）。
5. **報名表嵌入區**：開放前顯示「尚未開放」；開放後放 Google 表單 iframe。
6. **晉級公告區**：04/09 前顯示「尚未公告」。
7. **得獎公告區**：決賽後更新。
8. **FAQ**。
9. **頁尾**：主辦單位、聯絡 Email、Instagram。

## 怎麼更新內容
所有會變的內容（日期、狀態、名單）都集中在 `site/content.js` 一個檔案：
- 開放報名：把 `registrationOpen` 改成 `true`，貼上 Google 表單嵌入網址。
- 公告晉級：在 `finalists` 填入選手編號與曲目（**不放學號、電話、Email**）。
- 公告得獎：在 `winners` 填入。

## 個資規則
- 公告名單只放：選手編號、姓名（或藝名）、學校、曲目。
- 不放：學號、電話、Email、在學證明。
- 姓名公開前，報名表要有同意（已寫在章程附件二）。

## 部署步驟（第一次，約 10 分鐘）
1. 把分支 `claude/tender-pascal-4oczpg` 合併到 `main`。
2. GitHub repo → **Settings → Pages**。
3. Source 選 **GitHub Actions**（repo 已附 `.github/workflows/pages.yml`，推到 `main` 會自動部署 `site/`）。
4. 等約 1 分鐘，頁面上方會出現網址。
5. 之後每次改 `site/` 的檔案並推到 `main`，網站會自動更新。

## 驗收
- 手機寬度（375px）看得清楚，不需要左右滑。
- 「我要報名」按鈕在報名未開放時，會帶到「尚未開放」說明。
- 每個日期都和章程一致。
