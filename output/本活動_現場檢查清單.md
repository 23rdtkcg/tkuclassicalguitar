> 不懂的地方問總控。安全相關的段落寫完整句子，不要跳著看。

## T-7（活動前一週）
- [ ] 班表發給所有人。每人知道自己的職位和時間。
- [ ] 選手出場序公告。
- [ ] 評分表印 3 份×2（多一套備用）。
- [ ] 核分試算表測試過。兩人各算一次，結果一樣。
- [ ] 人氣獎表單測試過。一人只能投一票。
- [ ] 保險單拿到。影本放服務台。
- [ ] 活動申請核准公文拿到。影本放服務台。
- [ ] 對講機、延長線、急救箱借到。
- [ ] 野餐墊數量點過。登記表印好。

## T-1（前一天）
- [ ] 看天氣預報。告訴總控。
- [ ] 伴奏音檔全部下載到 2 台電腦。檔名＝出場序＋選手編號。
- [ ] 零錢準備好（野餐墊保證金找零）。
- [ ] 識別證、簽到表印好。
- [ ] 獎狀、獎品清點。放總控那裡。

- [ ] 舞台板穩。踩上去不晃。

- [ ] 觀眾區每 30 分鐘巡一次走道。
- [ ] 17:00 A 班、B 班交接。B 班簽到。
- [ ] 18:30 前開燈。

## 週五｜比賽中
- [ ] 計時員每組記錄時間。超時寫在記錄表。
- [ ] 每組唱完，評審接待收評分表前確認有簽名。
- [ ] 主持人不說任何分數。

## 週五｜核分與頒獎
- [ ] 評分表全部收齊：3 位評審 × 每組。
- [ ] 核分 A、B 各自輸入。不看對方。
- [ ] 對平均和名次。全部一樣才交總控。
- [ ] 不一樣：回去看紙本。改好再對。
- [ ] 同分：請評審討論投票。結果寫備註。
- [ ] 人氣獎投票截止。看結果。截圖存檔。
- [ ] 總控看過才交主持人宣布。
- [ ] 頒獎順序：人氣獎 → 季軍 → 亞軍 → 冠軍。
- [ ] 得獎者填領據。交事務行政。
- [ ] 評分表正本收進資料夾。交賽事運行組長。

## 緊急狀況（請完整讀完）

**打雷或閃電**：只要看到閃電或聽到雷聲，總控立刻宣布暫停。所有人離開舞台和帳篷下的電器。觀眾引導到室內。雷聲停止 30 分鐘後，總控才決定要不要繼續。

**大雨或強風**：帳篷開始被風吹動，就先把帳篷內的電器關掉。由總控決定是否把週四活動移到室內備案場地。不要讓工作人員爬上舞台或帳篷固定東西。

**有人受傷或身體不舒服**：一個人留在傷者旁邊，另一個人通知安全／急救人員和總控。意識不清、大量出血、呼吸困難，直接打 119，再通知校安中心。不要移動可能骨折的人。

**觸電或電線冒煙**：不要用手碰觸電的人。先關電源，再處理。

**觀眾太多、走道塞住**：觀眾區秩序人員通知總控。暫停入場，請後面的觀眾稍等。

**有人鬧事**：不要和對方爭吵。通知副控，由副控聯絡校安中心或警衛。
